# 🧬 Inheritance Odyssey — Advanced Python OOP Lab

> 🚀 Designing intelligent class hierarchies using **Python Object-Oriented Programming**

Welcome to **Inheritance Odyssey**, a curated collection of Python programs built to demonstrate powerful **Inheritance** concepts through real-world inspired system designs.

This repository transforms academic lab exercises into **professional software-style implementations**.

---

## ⚡ Project Overview

This project explores how software systems evolve through **class relationships**, **code reuse**, and **polymorphic behavior** using Python.

Each program represents a structured hierarchy modeled like real engineering systems.

---

## 🚀 Featured Programs

### 🏫 AcademicHierarchyEngine

**Multilevel Inheritance**

Simulates an academic structure:

* Department Management
* Course Organization
* Student Information System

---

### 🚗 VehicleInheritanceFramework

**Hierarchical Inheritance**

Models different vehicle categories:

* Base Vehicle System
* Car Specialization
* Bike Specialization

---

### 🛒 SmartCommerceEngine

**Inheritance + Polymorphism**

Implements an online shopping ecosystem:

* Product Base Architecture

### 👨‍💼 EnterpriseWorkforceManager

**Hierarchical Inheritance**

* Dynamic Bonus Calculation

---

### 🏆 StudentPerformanceFusion

**Multiple Inheritance & Polymorphism**
